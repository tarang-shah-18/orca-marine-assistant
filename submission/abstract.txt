ORCA is a conversational decision-support system for India's coastal fishermen, built on a collaborative multi-agent pipeline rather than a single prompt chain. A fisher asks a question in any of 11 Indian languages; ORCA detects the script, resolves the intent, plans a task graph, dispatches only the specialists that question needs, cross-checks their findings against one another, and answers in the same language with every number traceable to a named upstream product.

The system is registered against 13 agents: a planner, eleven domain specialists (GIS, PFZ, ocean state, weather, tide and current, marine alert, geofencing, route optimisation, risk validation, historical analysis, visualisation) and an independent critic that audits the rendered answer after the fact. Specialists run in dependency order over a shared blackboard and may request a second round from a peer, so a risk agent can send a question back to weather rather than guessing. Coverage spans 13 Indian harbours from Mumbai to Digha, 14 potential fishing zones, 14 statutory and ecological boundaries, 6 vessel classes and 12 distinct intents.

The engineering problem we took seriously is honesty, not fluency. A marine forecast API returns a well-formed response in which every value is null where its model has no grid cell. Naive averaging turns that into a confident "0.1 m waves, sea surface 0 degrees" stamped as real-time sea state, and a fisher acts on it. ORCA refuses to build a reading from an empty feed, falls back to a labelled reference snapshot, labels every product live or reference in the interface, and publishes the exact upstream failure reason on /api/status. It never states a location is "safe"; it ranks evidence, names what it is unsure about, and defers to IMD, INCOIS and the port authority.

The system is deployed and running at zero cost with no API keys: a React 19 and TypeScript client on Vercel, an Express engine on Render holding the live-data caches, chat rate limiter and SSE stream. Live data comes from keyless Open-Meteo endpoints (ECMWF IFS forecast, WaveWatch-III marine, ERA5 reanalysis) and the UN/European Commission's GDACS disaster feed. The same TypeScript core also runs inside the browser, so the app still answers when the server is unreachable. Validation is continuous: 71 offline unit tests and a 3,318-check regression sweep across the engine, all 11 languages, every endpoint and the SSE stream, all green on every commit.
